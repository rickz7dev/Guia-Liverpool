# Guia Liverpool

Site feito em React para a disciplina de Laboratório de Desenvolvimento Web (CESUPA).

É um guia para quem vai fazer intercâmbio em Liverpool, com os principais lugares para conhecer na cidade e algumas dicas úteis.

## Páginas

- **Home** - apresentação do guia
- **Lugares** - catálogo com os pontos turísticos da cidade
- **Dicas** - transporte, clima, dinheiro e outras dicas
- **Sobre** - informações sobre o projeto

## Tecnologias

- React (create-react-app)
- React Router
- CSS Modules

## Como rodar

```
cd guia-liverpool
npm install
npm start
```

Depois abrir http://localhost:3000 no navegador.
